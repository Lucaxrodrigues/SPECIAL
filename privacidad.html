Política de privacidad

Esta política describe el tratamiento de datos en el sitio comercial dropixeditoralivros.com, el proceso de compra y el aplicativo alfamaxapp.com.

1. Responsable

2. Datos del aplicativo

Para crear una cuenta se utiliza tu correo y se gestiona la autenticación mediante Supabase. La cuenta se vincula al correo de compra para comprobar los productos habilitados. Se guardan las tareas, fechas, espacios del hogar, estados de finalización y elementos de la lista de compras que introduzcas, además de los datos técnicos necesarios para mantener la sesión y proteger el servicio.

Los datos se utilizan para ofrecer las funciones solicitadas y permitir consultarlos desde tu cuenta. Evita escribir información sensible o datos de otras personas que no sean necesarios para organizar tus actividades.

3. Compra y entrega

Se utilizan nombre, correo, teléfono cuando se proporciona, referencias del pedido, productos, importe, moneda y registros de aceptación para procesar la compra, entregar el acceso y prestar soporte. Stripe procesa los datos de pago; no recibimos ni guardamos el CVC ni el número completo de la tarjeta en nuestro aplicativo.

4. Proveedores

Supabase proporciona autenticación, base de datos y almacenamiento del aplicativo; Cloudflare participa en el alojamiento y la infraestructura; Stripe procesa los pagos; n8n automatiza comunicaciones y vinculación de compras. Gmail y WhatsApp se utilizan para contacto y entrega. MemberKit u otra área indicada en las instrucciones puede conservar la entrega de materiales de compras anteriores. Telegram y WhatsApp se utilizan para la comunidad opcional.

Estos servicios pueden procesar datos en otros países. Aplicamos las medidas de transferencia que correspondan; no afirmamos que todos los datos permanezcan en Brasil. Los participantes de grupos pueden ver datos de tu perfil y, según el servicio y sus ajustes, tu teléfono. Revisa las opciones de privacidad antes de participar.

5. Medición publicitaria del sitio comercial

El sitio comercial y las páginas del proceso de compra pueden utilizar Meta Pixel, la API de conversiones y herramientas de analítica configuradas mediante Google Tag Manager. Se utilizan eventos de visita, inicio de checkout, datos de contacto proporcionados y compra para medir campañas y atribuir resultados.

Los datos pueden incluir URL, parámetros UTM, identificadores de clic y cookies como _fbp y _fbc, dirección IP, navegador, producto, importe y moneda. Cuando se envían correo y teléfono a Meta mediante la integración del servidor, se transforman con SHA-256; esto no los convierte en datos anónimos. No se envían a Meta datos completos de tarjeta. Las tareas y listas guardadas dentro del aplicativo no forman parte de esos eventos de compra.

La demo de la página comercial utiliza datos de ejemplo en memoria. La demo del aplicativo puede guardar ejemplos localmente en tu navegador. Estas demostraciones no crean una compra ni una cuenta de cliente.

6. Finalidades, bases y almacenamiento

El tratamiento necesario para compra, acceso y funcionamiento atiende la relación contractual; los registros exigibles se conservan para cumplir obligaciones legales. La seguridad y prevención del fraude se atienden con la base aplicable. Para publicidad y tecnologías no esenciales se aplicará la base jurídica y, cuando sea necesario, el consentimiento exigido en tu jurisdicción. Comprar no equivale a autorizar cualquier uso publicitario.

Las tareas y listas se conservan mientras sean necesarias para prestar el servicio o hasta que las elimines. Los datos de compra, soporte y registros técnicos se conservan según sus finalidades y las obligaciones aplicables. El acceso sin vencimiento no autoriza conservar todos los datos indefinidamente para cualquier fin. El navegador guarda información de sesión y preferencias; puedes eliminarla desde sus ajustes, lo que puede cerrar tu sesión.

7. Tus derechos y controles

Puedes eliminar tareas y elementos de la lista desde el aplicativo y exportarlos desde «Mi cuenta». Para acceso, corrección, eliminación de cuenta u otras solicitudes, escribe desde el correo de tu compra. Verificaremos la titularidad de forma proporcionada. Algunas obligaciones pueden exigir conservar registros aunque se elimine una cuenta. Antes de eliminarla, soporte explicará el efecto sobre el acceso.

Puedes solicitar información u oponerte al tratamiento cuando corresponda, retirar un consentimiento otorgado y acudir a la autoridad competente. Retirar el consentimiento no borra automáticamente datos ya tratados legítimamente. No envíes contraseñas por soporte.

8. Seguridad y cambios

Se utilizan autenticación y controles de acceso para proteger la información. Mantén tu contraseña privada. Las actualizaciones de esta política indicarán su fecha y reflejarán los servicios efectivamente utilizados.
